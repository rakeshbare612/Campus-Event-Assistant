Campus Event Assistant is a web-based application designed to help colleges manage and organize campus events efficiently. It provides a centralized platform where students can view upcoming events, register for activities, receive notifications, and track their participation. Administrators and event coordinators can create events, manage registrations, update event details, and monitor student participation.
Key Features
1. Student Login and Registration – Students can create accounts and log in securely.
2. Event Management – Admins can create, update, and delete campus events.
3. Event Registration – Students can register for technical fests, workshops, seminars, sports events, and cultural programs.
4. Event Notifications – Students receive updates about upcoming events, schedules, and venue changes.
5. Event Calendar – Displays upcoming events with dates, times, and locations.
6. Admin Dashboard – Allows administrators to manage events, registrations, and student records.
7. Attendance Tracking – Organizers can record student attendance at events.
8. Feedback System – Students can submit feedback and ratings after attending events.
Technology Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Python (Flask) or Node.js (Express)
- Database: MySQL
- Development Tool: VS Code
